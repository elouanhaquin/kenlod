# Sécurité

Kenlod héberge les documents d'associations, dont des données personnelles : la sécurité est prioritaire.

## Signaler une vulnérabilité

**N'ouvrez pas de ticket public.** Écrivez à **contact@kenlod.fr** en indiquant :
- la nature du problème et son impact possible ;
- les étapes pour le reproduire ;
- la version ou le commit concerné.

Vous recevrez une réponse sous quelques jours. La faille sera corrigée en priorité, et la correction publiée avec votre accord, en vous créditant si vous le souhaitez.

Merci de ne tester que sur votre propre instance, jamais sur kenlod.fr ni sur les données d'autres personnes.
